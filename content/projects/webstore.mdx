brief:
  problem: >-
    A studio wanted to sell ready made website templates online: customers browse templates by
    industry, preview them, pick a pricing tier, pay in their own currency, and then brief the
    build team on what to make. Customers pay in dollars or naira, and no single payment
    provider covers both well.
  approach: >-
    One Next.js app on Supabase and Vercel. Checkout uses each provider's hosted page, so no
    card data touches the app: Stripe for USD and CAD, Paystack for NGN, Flutterwave as the
    naira fallback. Webhooks gate each order on a confirmed payment. The app degrades instead of
    crashing when keys are missing, and an admin CMS behind a secret path runs the catalogue,
    pricing, and incoming briefs.
  outcome: >-
    Released as version 1.0.0 with a 1.0.1 hotfix, with regional pricing and add ons built on
    top. A suite of 330 tests runs against an in memory stand in for the database, so it is safe
    to run even though local development points at the live project.
