I design and build web systems for small teams that need them to work properly: real payments, real customer data, and nobody else on call when something breaks.

## How I work

I write the decision down before I write the code. Each feature starts as a short spec with the options I weighed and why one won. Then I build to that spec, check it in the running app, and add tests where the risk is real.

I use AI coding agents for much of the typing, not the thinking. The spec sets the boundaries, the checks catch mistakes, and a separate model reviews the change before it ships.
